Plateforme permettant aux commerçants belges de vendre leurs produits via un entrepôt centralisé.

## 🧠 Concept

- Entrepôt centralisé
- Panier multi-commerces
- Paiement sur place uniquement

## 🛠️ Stack technique

- Laravel
- Livewire
- Toastr JS
- Flux UI
- Architecture multi-rôles (Admin / Partenaires / Clients)
- Application développée entièrement en Laravel + Livewire
